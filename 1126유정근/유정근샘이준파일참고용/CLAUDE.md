# CLAUDE Guidelines

이 워크스페이스에서 작업을 시작할 때 최상위 루트의 [`law.md`](./law.md) 파일을 반드시 가장 먼저 읽고(`view_file`), 해당 파일에 정의된 모든 규칙과 프로젝트 지침을 철저히 준수해야 합니다.

### 필수 준수 규칙 (절대 누락 금지)
1. **`law.md` 최우선 열람**: 모든 작업 및 대화 시작 시 `law.md`를 실제로 도구(`view_file`)를 통해 가장 먼저 확인하고 그 지침을 따릅니다.
2. **스킬 탐색 및 적용**: 작업 요청 시 [`스킬/`](./스킬) 폴더의 스킬을 확인하여 활용합니다. 특히 스킬 생성 요청("~스킬 만들어줘" 등)은 [`스킬/skill-creator/SKILL.md`](./스킬/skill-creator/SKILL.md)를 즉시 열람하여 진행합니다.
3. **브라우저 사용 도구 지정**: 워크스페이스에서 웹 브라우저가 필요할 때는 `ego-browser`를 기본 브라우저 도구로 사용합니다. 브라우저 작업 전 `ego-browser` 스킬 지침을 확인하고, `ego-browser`를 사용할 수 없으면 사용자에게 설치·연동 상태를 알린 뒤 임의로 다른 브라우저로 대체하지 않습니다.
4. **산출물 폴더 집중 관리 (연월일시분 필수)**: 모든 작업 결과물은 최상위 루트가 아닌 [`deliverables/`](./산출물) 폴더에 생성해야 하며, 프로젝트 단위 작업으로 여러 파일이 생성될 경우 반드시 `deliverables/YYYYMMDD_HHMM_<프로젝트명>/` 폴더를 생성하여 관리합니다.
5. **답변 양식 준수**: 모든 답변의 맨 첫 줄에는 반드시 당 회차에서 열람한 파일 목록을 아래 형식으로 표기해야 합니다.
   - 형식: `열람파일 : [파일명](파일경로) 외 N개` (열람한 파일이 없을 경우 `열람파일 : 없음`)
